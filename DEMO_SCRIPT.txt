PART 2: THE MCP SERVER ARCHITECTURE & CAPABILITIES (0:35 - 1:20)
================================================================================
[ACTION: Scroll down to Installation (#install) and Agent Setup (#agents) sections. 
 Click between Codex, Claude Code, and AGY tabs]

"Getting started takes literally five seconds. Running 'npm install -g flowkit-mcp' 
installs the server locally with zero external API dependencies. 

Under the hood, FlowKit bundles and orchestrates four trusted native engines: 
Pandoc, ImageMagick, FFmpeg, and FFprobe.

It connects natively to any MCP client — Codex, Claude, or Google Antigravity.

When an agent needs to work with files, it calls typed tools like 
'flowkit_document_to_markdown', 'flowkit_image_resize', or 'flowkit_video_extract_audio'. 

FlowKit provides three critical architectural guarantees for agents:
1. Strict Sandboxing: Directory escapes like '../../' are rejected at the protocol layer. 
   The agent can never access files outside its workspace.
2. Schema Validation: Bad flags or invalid dimensions are caught before execution.
3. Bounded Previews: Instead of flooding the LLM's context window with megabytes of raw 
   bytes, FlowKit creates relative artifact files and returns compact text previews."
